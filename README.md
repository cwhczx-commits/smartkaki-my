# SmartKaki MY

Malaysia deal-aggregation landing page. Static site — no build step needed.

## Files
- `index.html` — page structure and content
- `styles.css` — mint/gold brand styling
- `script.js` — footer year + affiliate link placeholders

## Before going live
1. Replace the three placeholder links in `script.js` with your real
   Involve Asia deep links (Shopee, Lazada, Foodpanda).
2. Swap the sample deal codes/titles in `index.html` (`#deals` section)
   for real, currently-active promos.
3. Update the Telegram link if your channel handle changes.
4. Add your SSM registration number to the footer once registered.

## Deploy
Push this repo to GitHub, then import it into Vercel (see chat for
step-by-step instructions) — Vercel auto-deploys on every push to `main`.
